   - a miss recorded for an intraday timeframe;
   - bars stored for one.

   Either one signals that listing's chart history document on the bus the page already watches (`docs/architecture.md`: the server tells the page). A chart showing that listing asks again, and the buttons follow the answer.
   A miss that expires (`INTRADAY_RETRY_MINUTES`) only widens the set again, so it needs no signal: no button that fails is left, and the next answer offers the timeframe again.
