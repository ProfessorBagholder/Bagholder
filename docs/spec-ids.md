# SPEC.md rule ids

Every id ever given to a rule of `SPEC.md`, so that no id is given to a second rule. An id is `<section>-<n>`: the heading it was first given under and the next number unused there. It is never derived from the rule's words, so it stays the same when the wording changes or the rule moves. A new rule takes the next unused number under its heading and is added here; a rule that goes keeps its line here, marked `retired`. `test_every_rule_of_the_spec_has_an_id_given_once` (`rust/crates/server/src/tests_misc.rs`) holds the two files to each other.
